# Automata Lab

Automata Lab is an interactive educational web app for visually building and simulating DFA and NFA machines.

## Features

- Drag states and transitions onto a visual canvas
- Simulate strings character by character
- Explore epsilon and Sigma transitions
- Generate 5-tuples, transition formulas, and transition tables
- Detect DFA/NFA behavior
- Save machines as JSON or organized A4 PDFs
