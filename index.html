AUTOMATA LAB V1

How to use

Build Drag states onto the canvas. Choose Add transition arrow, then drag between states or back to the same state for a loop.

Label Select an arrow and choose its transition label from the dropdown. Sigma accepts any symbol in the alphabet; eps is epsilon.

Simulate Enter a string and press Run simulation. Click trace rows to inspect each character. Green means accepting; red means trapped or rejected.

Edit Drag states or arrows to move them. Use Delete to remove a selected item, and Ctrl+Z / Ctrl+Y for undo and redo.

Machines Use tabs to switch machines. They save in this browser automatically; Save downloads the current machine as JSON.
